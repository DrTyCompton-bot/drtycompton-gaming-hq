DRTYCOMPTON GAMING HQ — STARTER WEBSITE

Included:
- index.html: website content
- styles.css: tactical dark/green design and responsive layout
- script.js: mobile navigation, current year, Twitch player embed

NEXT STEPS:
1. Create a new public GitHub repository named drtycompton-gaming-hq.
2. Upload the three website files (index.html, styles.css, script.js) to the repository's main/root folder.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. Wait for GitHub Pages to publish. Your site URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/drtycompton-gaming-hq/

The Twitch player detects the deployed hostname automatically. It should work once the site is published.

CUSTOMIZE LATER:
- Edit index.html to change stream schedule, game roster, descriptions, and add social/community links.
- Replace the game roster cards as your content changes.
- Add your own logo, panda mascot artwork, Discord, YouTube, and other socials when ready.
